# Responsive React Navbar

A small React + Vite project that follows the supplied responsive-navbar brief.

## Breakpoints

- **Desktop (1024px and above):** white horizontal navbar with Logo, four links, and Create Account.
- **Tablet (768px to 1023px):** green navbar. The hamburger opens a full-width green menu while keeping links horizontal.
- **Mobile (up to 767px):** hamburger opens a full-screen green vertical menu. Create Account stays at the bottom.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
